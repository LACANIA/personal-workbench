# Personal Workbench 0.3.0-beta.1

这是面向外部测试人员的 Windows x64 Beta 版本。

下载后请先阅读 Release 资产中的 `README-FIRST-RUN.md`，其中包含安装、首次运行、模型准备、基本使用、退出、数据位置和问题反馈说明。

## 重点功能

- Local Ollama AI 与本机 Embedding。
- PDF、DOCX、PPTX、XLSX、TXT 和 Markdown Document Intelligence。
- Learning DOCX、Document Q&A 和本地资料检索。
- Video Knowledge 与可选本机媒体组件。
- File Organizer 扫描、预览、确认执行、历史和 Persistent Undo。
- Desktop First Run、Native Picker、Single Instance 和 Windows Tray。

## 已知限制

- 安装器尚未签名，Windows SmartScreen 可能提示未知发布者。
- 可选媒体运行环境没有随安装器分发，需要用户在应用中明确安装或配置。
- 短时间连续发起 Organizer 扫描可能留下无害的 draft 历史记录。
- 撤销成功后，Organizer 创建的空目录可能继续保留。
- 外部 Beta 阶段采用手动下载新版本，当前没有自动更新。

文件整理首次测试请使用新建的测试文件夹，并在处理重要资料前自行备份。
